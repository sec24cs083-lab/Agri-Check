# Architecture Overview

AgriCheck is a **Progressive Web App (PWA)** that combines a React/TypeScript frontend with a FastAPI Python backend, optional IoT sensor integration, and AI‑driven crop disease analysis. The system is designed for offline‑first usage in low‑connectivity farming environments.

## Data Flow
1. **User opens the PWA** – Service worker serves cached assets for offline usage.
2. **Login** – Frontend sends credentials to `POST /auth/login`; receives JWT stored in memory.
3. **Crop Scan** – Image uploaded → `POST /predict` → mock model returns prediction JSON.
4. **Feedback** – Farmer selects feedback → `POST /feedback` updates knowledge‑graph buffer.
5. **Continual Learning** – Backend processes buffered feedback periodically to retrain the mock model (simulated).
6. **Sensor Data** – ESP32 posts telemetry to `POST /sensor`; frontend polls `/sensor` for the latest readings.
7. **Weather** – Frontend fetches `/weather` (mock Open‑Meteo data) for advisory screens.
8. **Knowledge Graph** – `/knowledge-graph` returns nodes/edges for visualization.
9. **Mandi Prices** – Placeholder endpoint for future integration with `data.gov.in`.

---

## PWA Architecture
- **Service Worker** generated by `vite-plugin-pwa` caches `index.html`, JS bundles, CSS, and assets.
- **Manifest** (auto‑generated) enables "Add to Home Screen" on mobile devices.
- **Offline Strategy** – All UI screens load from cache; data requests fallback to mock responses when offline.

---

## Security Considerations
- No secret keys are hard‑coded in the repository. All credentials are loaded from environment variables (`.env.example`).
- JWT tokens are stored only in memory; not persisted to localStorage.
- CORS is restricted to the same origin in development.

## Future Extensions
- Replace mock AI model with a real Gemini API call (toggle via env variable).
- Integrate real weather APIs (Open‑Meteo) and mandi price APIs.
- Persist sensor data to a cloud database.
- Deploy backend to a cloud service (e.g., GCP Cloud Run) and frontend to GitHub Pages.
